# 🥗 Nutrition Myth-Buster Hub

A fun, interactive website dedicated to busting common nutrition myths with science-backed information. Explore myths, flip cards to reveal truths, and test your nutrition knowledge with our interactive quiz!

## ✨ Features

### 1. **Interactive Myth Cards**
- **5 Popular Myths** covering topics like carbs, late-night eating, detox juices, protein, and fats
- **3D Flip Animation** - Click any card to flip and reveal the truth
- **Cartoon Icons** - Cute emojis to represent each myth
- **Smooth Transitions** - Playful CSS animations with visual feedback

### 2. **Quiz Section**
- **5 True/False Questions** about nutrition
- **Instant Feedback** - Get immediate answers with explanations
- **Progress Bar** - Track your progress through the quiz
- **Score Display** - See your final score with percentage
- **Retake Option** - Test yourself again anytime

### 3. **Animations & Effects**
- **Balloon Pop Animation** - Colorful balloons burst when you flip myth cards
- **Confetti Celebration** - Confetti particles when you answer correctly
- **Shatter Effect** - Fragments appear when you answer incorrectly
- **Smooth Scroll Navigation** - Easy navigation between sections
- **Responsive Canvas** - Dynamic animations using HTML5 Canvas

### 4. **Design Highlights**
- **Bright, Approachable Colors**
  - Primary: Coral Red (#FF6B6B)
  - Secondary: Teal (#4ECDC4)
  - Accent: Sunny Yellow (#FFE66D)
  - Success: Mint Green (#95E1D3)

- **Cartoon-Style UI**
  - Rounded corners and playful fonts
  - Gradient backgrounds
  - Emoji icons throughout

### 5. **Mobile-Friendly**
- **Responsive Grid Layout** - Adapts from 1-3 columns based on screen size
- **Touch-Friendly Buttons** - Large, easy-to-tap elements
- **Optimized for All Devices** - Breakpoints at 768px and 480px
- **Flexible Navigation** - Collapsible menu on mobile
